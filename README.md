# Bixell marketplace

Claude Code plugins from Bixell.

| Plugin | What it does |
|---|---|
| [branch-manager](plugins/branch-manager) | Boots an Office of Claude agents run by Michael, the orchestrator. |

## Install

```bash
claude plugin marketplace add bixell/bixell-marketplace
claude plugin install branch-manager@bixell-marketplace
```

This is a public repository, so no GitHub access is needed. The commands above work for anyone with Claude Code installed.
